# 🎓 SOS Learning Management System (LMS)

Welcome to the **SOS Learning Management System (LMS)** project.

This project is being developed by students as an **Object-Oriented Programming
(OOP) application project** for SOS.

The objective is to design and develop a functional LMS that can support the
academic and learning activities of SOS through a structured, user-friendly
and deployable web application.

---

## 🎯 Project Objective

The main objective of this project is to apply Python Object-Oriented
Programming concepts to develop a real-world Learning Management System.

Students are expected to transform their OOP knowledge into a complete
application with:

- Python-based backend/application logic
- Object-Oriented Programming
- Streamlit user interface
- Database/data management where required
- Deployment
- GitHub-based project development

---

## 🏫 About the LMS

The SOS LMS is intended to provide a centralized platform for managing
learning-related activities.

Depending on the assigned module or feature, the system may include:

- 👨‍🎓 Student management
- 👨‍🏫 Faculty/Trainer management
- 📚 Course management
- 📖 Module management
- 📝 Assignment management
- 📊 Student progress tracking
- ✅ Attendance management
- 💰 Fee/payment management
- 📅 Class/session management
- 📢 Announcements
- 📈 Reports and dashboards
- 🔐 User/login management

The exact features may vary depending on the student's assigned module.

---

# 🧩 OOP Requirement

A major objective of this project is to demonstrate **proper Object-Oriented
Programming**.

The main application logic should be implemented through:

- Classes
- Objects
- Attributes
- Methods
- Constructors
- Encapsulation
- Appropriate relationships between classes
